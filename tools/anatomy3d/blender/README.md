# Сборка анатомических моделей RYNJI (Blender, headless)

Модели собираем сами из открытого атласа **Z-Anatomy** (CC BY-SA 4.0; мышцы и кости — **BodyParts3D**, CC BY-SA 2.1 Japan).
Ничего не покупается. Рендеры — производные работы и распространяются под **CC BY-SA 4.0** с указанием авторства
(см. `docs/ASSETS_LICENSES.md`). Архитектура — `../README.md`.

```bash
pip install bpy scipy pillow                  # Blender 5.0 как модуль Python, KD-дерево/оболочки, сборка кадров
./build_all.sh                                # атлас → male.blend, female.blend (~/.cache/rynji-anatomy/models)
M=~/.cache/rynji-anatomy/models
python -I rig.py -- $M/male.blend $M/male_rig.blend      # арматура и веса
python -I rig.py -- $M/female.blend $M/female_rig.blend
# ракурсы и примеры подсветки (основные; вспомогательные — базовые имена мышц атласа через «;»)
W=720 H=1280 SAMPLES=48 python -I render_views.py -- $M/male.blend out front,back,q34 "Latissimus dorsi muscle" "Teres major muscle"
python onwhite.py sheet.png out/front.png out/back.png out/q34.png   # белый фон, мягкое свечение, лист кадров
# ролик упражнения: кадры PNG (ONLY=0,36 — только эти кадры, для проверки)
W=640 H=480 SAMPLES=16 python -I anim.py -- $M/male_rig.blend ../exercises/pec_deck.json ../atlas_map.json frames/pec_deck
```

| Сценарий | Что делает |
|---|---|
| `fetch_atlas.sh` | клонирует атлас, распаковывает `Startup.blend` (≈300 МБ) вне репозитория |
| `build_male.py` | ~210 мышц (поверхностные и закрывающие просветы глубокие), сухожилия и апоневрозы, ~210 костей, кожа головы, кистей и стоп, глаза; нормали наружу; положение объектов (в т. ч. дельта-трансформации атласа) — в вершины; материалы; части атласа под NC-лицензиями не берутся |
| `physique.py` | прирост толщины каждой поверхностной мышцы по брюшку (ноль у сухожилий) вдоль сглаженной нормали; лежащие поверх выталкиваются, глубокие не прорезают поверхностные. `male` — бодибилдер (×1,5), `female` — ягодицы и ноги относительно больше, верх меньше (×0,5) |
| `morph_female.py` | уже плечи и грудная клетка, тоньше талия и шея, шире таз и бёдра (Q-угол), руки короче и тоньше, голова относительно крупнее, рост 1,62 м; кости, мышцы и кожа деформируются одним полем — крепления на месте |
| `female_extras.py` | грудь (под топом), волосы-скульптура по черепу с линией роста волос и пучок |
| `garment.py` | одежда по выпуклой оболочке срезов тела: плавки; топ с лямками через надплечья и трусы |
| `rig.py` | центры суставов по контакту костей (головки плечевой и бедренной — подгонка сферы), 43 кости; веса — обратные расстояния до костей своего участка тела, сглаженные в пространстве; кисти — без сглаживания |
| `posing.py` | позы по суставным углам и ИК кисти к рукояти |
| `stage.py`, `anim.py` | свет, камера по азимуту/возвышению, подсветка по `atlas_map.json`, тренажёры, ключи анимации, рендер кадров |
| `render_views.py`, `onwhite.py` | ракурсы модели; белый фон и мягкое свечение подсветки |

Запускать Python с `-I`, `.blend` атласа открывается с `use_scripts=False` (встроенные сценарии атласа не выполняются).
