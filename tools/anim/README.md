# 3D-анимации техники RYNJI

Собственный пайплайн: процедурная анатомическая фигура на three.js → движение по биомеханике упражнения →
рендер в headless Chromium (WebGL2, SwiftShader) → зацикленный анимированный WebP + постер JPEG.
Сторонние модели, фотографии и лицензированные анимации не используются — права на все файлы наши.

## Как устроено

| Файл | Что делает |
|---|---|
| `web/body.js` | Скелет (суставы и длины звеньев) и анатомия: 89 анатомических объёмов — эллипсоиды и скруглённые конусы, 15 мышечных групп, гладкое объединение SDF, полигонизация surface nets. Цвет вершины = группа мышц: основные — ярко-зелёные, вспомогательные — бледные, остальное — серое; шорты и обувь — отдельные объёмы |
| `web/rig.js` | Поза: корпус — прямой кинематикой, руки и ноги — двухзвенной IK с полюсом локтя/колена; кисть держит снаряд |
| `web/motions.js` | Сцены упражнений: снаряды, камера, подсветка (`primary`/`secondary`) и поза как функция фазы повторения `p ∈ [0,1]`. В комментарии к каждой сцене — биомеханика, по которой она проверена |
| `web/props.js` | Штанга, гантели, скамья, блочный тренажёр, рукоять, трос |
| `web/stage.js` | Студия: фон с зелёным свечением, ключевой/заполняющий/контровой свет, тень на полу |
| `render.cjs` | Рендер кадров цикла (по умолчанию 60 кадров 1280×960) и сборка WebP |
| `encode.py` | PNG → WebP (640 px, 25 к/с, бесконечный цикл) + постер (середина цикла, 360 px) |
| `manifest.json` | Отметка проверки биомеханики (`checked`) и заметки по каждому упражнению |
| `registry.ts` | Генерирует `src/data/exerciseAnimations.ts` (статичные `require` для Metro) и `docs/ANIMATION_COVERAGE.md` |

## Команды

```bash
# рендер упражнений (кадры → tools/anim/out/<id>/, результат → assets/anim/<id>.webp и posters/<id>.jpg)
node tools/anim/render.cjs back_squat bench_press
# переменные: FRAMES=60 W=1280 HH=960 H=0.008 (шаг сетки фигуры), NO_ENCODE=1 — только кадры
# превью фигуры в покое с подсветкой
node tools/anim/preview.cjs tools/anim/out/preview '[["chest"],["triceps"]]'
# реестр и карта анимаций для приложения
npx tsx tools/anim/registry.ts
```

Требуется Chromium с Playwright (`PLAYWRIGHT_PATH`, если пакет установлен глобально) и Python 3 с Pillow.

## Добавить упражнение

1. Сцена в `web/motions.js`: снаряды (`setup`), поза по фазе (`pose(p)`), привязка снаряда к кисти (`after`), камера, подсветка мышц.
2. Проверить кадры начала, середины и конца цикла с нескольких ракурсов; записать заметку и `checked: true` в `manifest.json` только после проверки.
3. `node tools/anim/render.cjs <id>` → `npx tsx tools/anim/registry.ts`.
