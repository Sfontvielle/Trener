# RYNJI 2.0 — фаза B: основа дизайн-системы

Все снимки — **web-рендер** 393×852 в Linux Chromium (шрифт Inter вместо SF Pro). На iPhone не проверено на устройстве.

## Что изменилось

| Шаг | Что сделано |
|---|---|
| B1. Цвет | Токены Precision Performance (`src/theme/tokens.ts`): тёмная и светлая палитры × 3 акцента. Тест: значения в палитре уникальны, текст и цвета данных проходят WCAG AA ≥ 4,5:1 |
| B2. Текст | Шкала display / title1 / title2 / headline / body / callout / footnote / caption, табличные цифры. Не мельче 12 pt, без сверхжирного 800. Отступы 4/8/12/16/24/32, 5 радиусов |
| B3. Компоненты | Кнопка 52 / 48 / 38 без свечения, чип со скруглением 8, переключатель-капсула (подписи переносятся, а не обрезаются), заголовки секций, пустые состояния. Новое в `src/components/ds/`: AppHeader, Group + ListRow, StatRow, Scale, ErrorState, LoadingSkeleton, PrimaryAction, SecondaryAction, NativeSheet. Числа ru-RU: `fmtValue`, `fmtUnit`, `fmtDelta` |
| B4. Лист | Пружина damping 26 / stiffness 260; при «Уменьшении движения» лист проявляется на месте за 120 мс; заголовок title2 |
| B5. Таб-бар | Подпись 12 pt; выбранная вкладка — основным цветом текста и полосой акцента 2 pt сверху |
| B6. Движение | Убраны фоновые свечения, свечение и блик кнопок, ореол «✓» в тренировке, свечения анкеты. Экран открывается сразу целиком, без «лесенки». Числа и полосы двигаются только после действия |
| B7. Пакеты | `npx expo install --fix`: 18 пакетов до версий SDK 58 (expo 58.0.22, react-native 0.88.1, expo-router 58.0.29 и др.); `expo-doctor` 20/20 |

Экран `/dev-ds` — каталог компонентов, доступен только в сборке разработки.
