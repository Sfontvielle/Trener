# RYNJI 2.0 — фаза F: доступность, производительность, полировка, App Store

Все проверки — в web-рендере (Linux Chromium) и в Node. На iPhone не проверено на устройстве: список того, что может проверить только владелец, — в конце.

## Что сделано

| Шаг | Что изменилось |
|---|---|
| F1. Крупный шрифт | У основного текста предел роста ×2, поэтому проверка ×2 покрывает и AX5. Нашлось то, чего веб не видел: 9 из 14 полей ввода росли без предела (на AX5 — в 3 раза при фиксированной высоте поля). Теперь у всех полей предел ×1,3. Иконки не масштабируются (у них `allowFontScaling: false`) |
| F1. VoiceOver | Новый режим аудита `A11Y_VO=1`: у каждого экрана есть заголовок, цели нажатия не меньше 24 pt в разметке, разные кнопки не называются одинаково. Найдено и исправлено: 16 экранов без заголовка (старая шапка, итоги тренировки, состав, название упражнения); текстовые ссылки высотой 20 pt — теперь 44 pt без сдвига вёрстки (`linkHit`); одинаковые названия — «Подход выполнен» ×2, «Уверенность: средняя» ×6, «Добавить» ×3, «Авто» ×2, «Продолжить» ×2; кнопка «Во весь экран» у 3D была 17×19 — теперь 44×44 |
| F2. Уменьшение движения | Учитывается везде: графики сразу показывают итог, календарь раскрывается без анимации, тост и боковая панель проявляются на месте, без сдвига; импульсы таймера и сканера не играются |
| F2. Контраст | Тесты темы проверяют все 6 палитр (2 темы × 3 акцента): текст на поверхностях, на `surface3` и на цветных подложках (4,5:1); графику — мышцы на схеме, значки статуса и бегунок переключателя (3:1, WCAG 1.4.11). Нашлось: вспомогательные мышцы в светлой теме — 2,3:1; исправлено на 3,4:1 |
| F3. Производительность | `npm run perf`: год данных из демо-генератора приложения — 2 583 записи питания, 181 тренировка, 253 взвешивания. Всё, что считается при открытии экранов, укладывается в 2,7 мс (Node). Единственное узкое место — подбор еды для подсказки в дневнике: 38 мс в типичном случае. Ускорен без изменения результата (выдача совпадает байт в байт на 576 случаях) и вынесен с пути отрисовки: остаток показывается сразу, вариант еды досчитывается в свободное время |
| F3. Отрисовка на годе данных | `scripts/perf-web.cjs`: месяц и год данных отличаются на 0–70 мс при открытии каждого экрана; история — на виртуализированном `FlatList`. Запись на диск отложенная, сериализация года — 3,7 мс (Node), один раз после серии изменений |
| F4. «Техника» | Блоки на дизайн-системе: заголовки headline (с ролью заголовка), текст по шкале, нейтральные номера шагов; «Амплитуда» и «Дыхание» — друг под другом вместо двух сжатых колонок; цвет — только у предупреждений |
| F4. Мелочи | Офлайн-ответ тренера — числа с разделителем разрядов; тексты анализов не обещают распознавание PDF и фото, когда в сборке нет сервера; обращение на «ты» везде |
| F5. Регрессия снимков | `scripts/visual-web.cjs`: дневник и тренировка (до и после записанного подхода), тёмная и светлая тема. Время в браузере зафиксировано, данные — демо-история от этой даты, сравнение — попиксельно, допуск 0,5%. Два прогона подряд — 0,00% |
| F5. CI | `.github/workflows/ci.yml`: типы, линтер, юнит-тесты; затем регрессия снимков на Ubuntu 24.04 с Inter и Playwright 1.63. Первый прогон показал, что CI рисует системный шрифт по-другому (3,5–4,6% пикселей); перед снимком текст теперь явно переводится на Inter |
| F6. App Store | Манифест приватности в `app.json`. Пакеты SDK 58 обновлены до ожидаемых версий (`expo-doctor` 20/20). В `docs/appstore`: чек-лист, тексты для витрины, политика конфиденциальности и ответы App Privacy — по фактическим потокам данных; черновики снимков 1320×2868 (web-рендер) |

## Что проверить на iPhone (может только владелец)

1. **VoiceOver**: начать тренировку → записать подход → завершить; добавить еду; чек-ин. Названия кнопок и порядок чтения.
2. **Крупный шрифт до AX5** («Универсальный доступ → Дисплей и размер текста»): «Сегодня», дневник, добавление еды, тренировка — ничего не обрезается, поля ввода читаются.
3. **Уменьшение движения**: листы, тосты, графики без сдвигов.
4. **Устройства**: маленький экран (SE, 375 pt), экран с Dynamic Island, светлая и тёмная тема.
5. **Производительность на годе данных** (демо-история за год в сборке разработки): прокрутка истории и дневника, время появления подсказки по остатку, нет подтормаживания при добавлении еды (запись на диск).
6. **Нативное**: разрешения Apple Health, Live Activity во время тренировки, уведомления, вход через Apple ID, сканер штрихкодов, тактильный отклик.

## Решения владельца

См. `docs/appstore/README.md`: учётная запись Apple Developer, адрес политики конфиденциальности, режим Enhanced в первой версии (правило App Review 1.4.3), включение AI-сервера тренера (тогда меняются политика, ответы App Privacy и манифест), возрастной рейтинг. Из прошлых фаз: приветствие со свечением, карточки целей с 3D-торсами, лицензированная анатомическая модель, FatSecret.
