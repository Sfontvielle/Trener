# RYNJI — принципы интерфейса

Спокойный премиальный интерфейс в духе iOS: тренер, а не панель приборов. Тёмная тема и лаймовый акцент сохраняются.

## Правила экрана

1. **Один экран — одна задача.** Главное — сверху, крупно; второстепенное — ниже или за «Ещё / Подробнее / Данные ›».
2. **Один акцент и одно основное действие.** Лайм (`colors.accent`) — у главной кнопки экрана. Выбор, переключатели,
   вторичные действия — нейтральные: светлая «пилюля» (`colors.text` на фоне) или заливка `surface2/surface3`.
3. **Минимум карточек и рамок.** Главный блок экрана — на фоне, без карточки. Группы данных — один список на
   `surface` со скруглением 22 и тонкими разделителями (`0.5`, `borderStrong`). Цветная рамка — только у опасного
   (`Card tone="danger"`, здоровье).
4. **Минимум текста.** Без поясняющих сносок под каждым блоком: объяснение — по «Почему ›» или в листе.
   Подписи — обычным регистром, без капса и разрядки.
5. **Без дублирования.** Одна цифра — в одном месте экрана (например, КБЖУ дня — строка «Питание» на главной).
6. **Функции не удаляются** — упрощается их подача: редкие разделы сворачиваются, но остаются в один тап.

## Токены

| | Значение |
|---|---|
| Фон | `#000000` (OLED) |
| Поверхности | `surface #121214`, `surface2 #1B1B1E`, `surface3 #27272B` |
| Текст | `text #F5F5F0`, `textDim #9C9CA2`, `muted #64646A` |
| Акцент | `#C8F53C` — главное действие экрана |
| Поля | 20 по краям; между смысловыми блоками — 28–40 |
| Типографика | `display 40/800`, `h1 32/800`, `h2 22/700`, `h3 18/700`, `body 16/500`, `small 14`, `caption 13/600` (без капса) |
| Кнопки | основная — лаймовая «пилюля» 56; вторичная — заливка `surface3`; `outline` выглядит как `secondary` |
| Переключатель | отдельные «пилюли» без подложки; длинные подписи — прокрутка по горизонтали до краёв экрана (`bleed`), выбранная сама прокручивается в поле зрения |

## Компоненты

- `Card` — заливка без рамки; `tone="danger"` — единственная цветная рамка.
- `Segmented` — «пилюли»; выбранная — `surface3`.
- `Chip` — выбранный: светлый (`colors.text`), не лаймовый.
- `SectionTitle` — заголовок раздела обычным регистром; действие справа — нейтральное.
- `DecisionCard` — что → почему → уверенность; данные и источник правила — по «Данные ›».
- `CoachFeed` — до трёх карточек, остальное — «Ещё N».
- `GlassSurface` — «жидкое стекло» iOS 26 для нижнего меню и панели тренировки (с запасным вариантом).

## Доступность

Крупный шрифт проверяется `A11Y_SCALE=2 node scripts/a11y-web.cjs` (28 экранов): текст не вылезает, у каждой кнопки
есть название для VoiceOver. Подписи для VoiceOver при редизайне сохраняются — на них опираются e2e-тесты.
