# RYNJI — принципы интерфейса

Тёмный премиальный интерфейс в духе iOS: тренер, а не панель приборов. Минимализм — через сокращение содержимого,
иерархию и раскрытие по требованию, а не через обесцвечивание. Один лаймовый акцент, живое и деликатное движение.

## Правила экрана

1. **Один экран — одна задача.** Сверху — крупно то, что нужно прямо сейчас; второстепенное — ниже, в листе (sheet),
   за «Ещё / Подробнее / Все показатели ›» или на следующем экране.
2. **Один акцент и одно основное действие.** Лайм (`colors.accent`) — у главной кнопки экрана (`Button live`).
   Выбор, переключатели и вторичные действия — нейтральные: светлая «пилюля» или заливка `surface2/surface3`.
3. **Минимум карточек и рамок.** Главный блок — на фоне, без карточки. Списки — строками с тонким разделителем
   (`0.5`, `borderStrong`); подложка `surface` — только у одного списка-группы. Цветная рамка — только у опасного.
4. **Минимум текста.** Без сносок под блоками: объяснение — по тапу на цифру или «Почему ›». Подписи — обычным регистром.
5. **Без дублирования.** Одна цифра — в одном месте: сегодняшняя тренировка крупно — на «Сегодня», неделя — на
   «Тренировках», КБЖУ подробно — на «Питании», вес — на «Прогрессе».
6. **Функции не удаляются** — меняется подача: редкие разделы сворачиваются, но остаются в один тап.

## Информационная архитектура

| Экран | Главное (первый экран) | Где остальное |
|---|---|---|
| Сегодня | состояние дня, тренировка крупно, фокус тренера одной строкой, «живая» кнопка, 3 кольца (готовность, ккал, вода), одна строка тренера | все сигналы тренера и чат — лист по строке тренера; дневник дня, шаги, заметки, календарь — лист по дате; состав — по строке параметров |
| Тренировки · Неделя | «X из N» крупно, дни недели списком, у сегодняшнего — «Начать» | план и сплит, шаблоны, объём — строками в листы |
| Тренировки · Дневник | лента по неделям, итог недели — в заголовке | календарь месяца и день — по кнопке |
| Питание | кольцо «осталось ккал», 4 макроса, «Добавить еду», приёмы пищи одним списком | почему такие КБЖУ — тап по кольцу; частые, недавние, «как вчера» — в листе добавления |
| Прогресс | тренд веса крупно, график, период, одна фраза «что изменилось» | отчёт недели, анализы — строки; тело, сила, рекорды — ниже; таблицы 8 недель, объём, сон — «Подробная статистика» |
| Тренировка | секундомер, «1 из 6 ‹ ›», упражнение, рекомендация, подходы, одна кнопка | техника, замена, суперсет, дискомфорт — «•••»; почему такой вес и блины — тап по рекомендации |
| Чек-ин | сон крупно, самочувствие, «Сохранить» | колесо сна — по тапу; мышцы, стресс, боль, вес — «Ещё» |

## Движение (`src/components/motion.tsx`)

- `Tap` — пружина нажатия (scale + лёгкое затемнение) для кнопок, строк и колец.
- `Appear` / `FadeIn` — появление «лесенкой» (прозрачность + подъём на 6–10 pt, шаг 70 мс).
- `Button live` — главное действие: мягкое «дышащее» свечение под кнопкой (`CtaGlow`) и редкий блик (`Sheen`).
- `Ambient` — фоновый свет вверху экрана; цвет отражает состояние дня: лайм — тренировка, холодный — отдых, тёплый — поберечься.
- `Progress`, `Ring`, `useCountUp` — полосы и кольца «наливаются», главные числа досчитываются.
- `Segmented` — подложка выбранной вкладки переезжает пружиной; длинный ряд прокручивается к выбранной.
- `Toggle` — бегунок на пружине.
- «Уменьшение движения» (iOS) и автотесты в браузере видят итоговое состояние сразу, без анимации.

## Токены

| | Значение |
|---|---|
| Фон | `#000000` (OLED) + `Ambient` |
| Поверхности | `surface #121214`, `surface2 #1B1B1E`, `surface3 #27272B` |
| Текст | `text #F5F5F0`, `textDim #9C9CA2`, `muted #64646A` |
| Акцент | `#C8F53C` — главное действие экрана |
| Поля | 20 по краям; между смысловыми блоками — 28–40 |
| Типографика | `hero 50/800` (главное слово экрана), `display 40`, `h1 32`, `h2 22`, `h3 18`, `body 16`, `small 14`, `caption 13` |
| Кнопки | главная — лаймовая «пилюля» 56 с `live`; вторичная — `surface3`; `ghost` — текст |

## Метрика простоты

`node scripts/ux-fold.cjs --compare docs/ux-fold-baseline.json` считает, что видно на первом экране каждого основного
экрана (текстовые блоки, иконки, нажимаемые элементы, подложки, слова) и сравнивает с версией до упрощения
(`docs/ux-fold-baseline.json`, коммит 8ccdf51).

## Доступность

Крупный шрифт — `A11Y_SCALE=2 node scripts/a11y-web.cjs`: текст не вылезает, у каждой кнопки есть название для
VoiceOver. Значения разделов профиля, свёрнутые с экрана, читаются VoiceOver как подсказка строки.
