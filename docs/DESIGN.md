# RYNJI — принципы интерфейса

Тёмный премиальный интерфейс в духе iOS: тренер, а не панель приборов. Минимализм — через сокращение содержимого,
иерархию и раскрытие по требованию, а не через обесцвечивание. Один лаймовый акцент, живое и деликатное движение.

## Правила экрана

1. **Один экран — одна задача.** Сверху — крупно то, что нужно прямо сейчас; второстепенное — ниже, в листе (sheet),
   за «Ещё / Подробнее / Все показатели ›» или на следующем экране.
2. **Один акцент и одно основное действие.** Лайм (`colors.accent`) — у главной кнопки экрана (`Button live`).
   Выбор, переключатели и вторичные действия — нейтральные: светлая «пилюля» или заливка `surface2/surface3`.
3. **Минимум карточек и рамок.** Главный блок — на фоне, без карточки. Списки — строками с тонким разделителем
   (`0.5`, `borderStrong`); подложка `surface` — только у одного списка-группы. Цветная рамка — только у опасного.
4. **Минимум текста.** Без сносок под блоками: объяснение — по тапу на цифру или «Почему ›». Подписи — обычным регистром.
5. **Без дублирования.** Одна цифра — в одном месте: сегодняшняя тренировка крупно — на «Сегодня», неделя — на
   «Тренировках», КБЖУ подробно — на «Питании», вес — на «Прогрессе».
6. **Функции не удаляются** — меняется подача: редкие разделы сворачиваются, но остаются в один тап.

## Информационная архитектура

| Экран | Главное (первый экран) | Где остальное |
|---|---|---|
| Приветствие | только при первом запуске: знак RYNJI собирается (кольцо → бицепс) с двойным зелёным импульсом, затем «Тренировки под твои цели.» и «Начать» | обычный запуск — сразу приложение |
| Вход | Apple ID (системная кнопка) или «Продолжить без входа»; честно: данные пока только на iPhone, iCloud — отдельным этапом | привязать/отвязать — Профиль → Аккаунт |
| Анкета | «N из 5» по центру с полосой: имя → о тебе (пол иконками, возраст 18+, рост, текущий вес — пустые поля, ничего не подставляем) → цель (набор массы / сушка / рекомпозиция / поддержание) → тренировки (опыт, дни недели, длительность, зал/дом и оборудование) → образ жизни (работа, шаги, сон, ограничения) → старт. Каждый ответ сохраняется: после закрытия приложения анкета продолжается с того же этапа | целевой вес и срок не спрашиваем; темп цели — рекомендованный, меняется в Профиле; предпочтения в еде — позже, тренер напомнит |
| Главная | дата (дневник дня), тренировка дня крупно с «живой» кнопкой; карточки: калории и БЖУ (кольцо + три полосы), шаги и вес с недельной динамикой и мини-графиком, сон и восстановление (готовность), RYNJI Coach (главный сигнал + «Спросить»), вода строкой. Профиля в шапке нет — он во вкладке | все сигналы тренера с «Спросить тренера» у каждой рекомендации и «Почему такой план» — лист по карточке тренера; без данных — пустое состояние с действием (чек-ин, Apple Health, записать вес), никаких примерных цифр |
| Тренировки · Неделя | календарь недели (свайп и стрелки — прошлые и следующие недели), «X из N» крупно, дни списком | план и сплит, объём — строками в листы |
| Тренировки · Дневник | лента по неделям, итог недели — в заголовке | календарь месяца и день — по кнопке |
| Перед тренировкой и сгенерированная | название и параметры по центру, упражнения с «гифкой» движения, мышцами и подходами, одна кнопка; без «фокуса» и объяснений | целевые мышцы — ниже списка; тап по «гифке» — техника |
| Тренировка | одно упражнение — один экран: «1/5» слева, секундомер по центру (▾ — калории, список, завершить); название акцентом, мышцы, «Прошлый раз» одной строкой (тап — рекомендация и история), подходы крупно «55 кг × 12»; внизу — «Техника» (раскрывает нижний раздел: место под 3D-анимацию, кадры движения, мышцы, подсказки), «i» (рекомендация); панель ‹ + ✓ ⏱ › | таймер отдыха — только вручную (⏱), автоматически не запускается; замена, суперсет, убрать подход, дискомфорт — «•••»; раскладка блинов — в «i» |
| Итог тренировки | время, объём, упражнения | разбор тренера — кнопка ✦ сверху |
| Питание | кольцо «осталось ккал», «X из Y», 4 макроса, приёмы пищи с Б·Ж·У | почему такие КБЖУ — тап по кольцу; сканер штрихкода с запасными путями (поиск, ввод кода, продукт с этикетки) |
| Прогресс | тренд веса крупно, график, период, одна фраза «что изменилось» | Тело, Статистика, Отчёт недели, Анализы — строками |
| Тело | процент жира диапазоном и уровень, анализ фото, что подтянуть (+ акцент в плане одним нажатием) | запас жира, пропорции, замеры и сравнение фото — ниже |
| Статистика | вкладки: Сила · Нагрузка · Восстановление | рабочие веса и рекорды, 8 недель, объём по мышцам, сон |
| Анализы | последний отчёт (сколько ухудшилось / улучшилось / вне референса), последние значения с мини-графиками | отчёт по каждой загрузке, таблица всех анализов, история показателя |
| Чек-ин | сон крупно, самочувствие, «Сохранить» | колесо сна — по тапу; мышцы, стресс, боль, вес — «Ещё» |

## Движение (`src/components/motion.tsx`)

- `Tap` — пружина нажатия (scale + лёгкое затемнение) для кнопок, строк и колец.
- `Appear` / `FadeIn` — появление «лесенкой» (прозрачность + подъём на 6–10 pt, шаг 70 мс).
- `Button live` — главное действие: мягкое «дышащее» свечение под кнопкой (`CtaGlow`) и редкий блик (`Sheen`).
- `Ambient` — фоновый свет вверху экрана; цвет отражает состояние дня: лайм — тренировка, холодный — отдых, тёплый — поберечься.
- `Progress`, `Ring`, `useCountUp` — полосы и кольца «наливаются», главные числа досчитываются.
- `Segmented` — подложка выбранной вкладки переезжает пружиной; длинный ряд прокручивается к выбранной.
- `Toggle` — бегунок на пружине.
- `BrandMark` — знак RYNJI; с `animate` собирается (кольцо дорисовывается, бицепс пружиной, двойной импульс) — на приветствии.
- Календарь недели — сдвиг влево/вправо при перелистывании; отчёт анализов — плавная смена списка по плитке.
- «Уменьшение движения» (iOS) и автотесты в браузере видят итоговое состояние сразу, без анимации.

## Метрика простоты

`node scripts/ux-fold.cjs --compare docs/ux-fold-baseline.json` считает, что видно на первом экране каждого основного
экрана (текстовые блоки, иконки, нажимаемые элементы, подложки, слова) и сравнивает с версией до упрощения
(`docs/ux-fold-baseline.json`, коммит 8ccdf51).

## Доступность

Крупный шрифт — `A11Y_SCALE=2 node scripts/a11y-web.cjs`: текст не вылезает, у каждой кнопки есть название для
VoiceOver. Значения разделов профиля, свёрнутые с экрана, читаются VoiceOver как подсказка строки.
