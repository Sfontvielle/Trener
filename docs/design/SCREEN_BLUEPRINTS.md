# RYNJI 2.0 — структура экранов (фаза A)

Компоненты и токены — из `RYNJI_DESIGN_SYSTEM.md`. Пять контрольных экранов (★) нарисованы в `docs/design/mockups/` до массовой замены интерфейса. Каркасы ниже — порядок и вес блоков; размеры условные.

Общее для всех экранов:
- Вкладки: Сегодня, Тренировки, Питание, Прогресс, Профиль (5, без изменений).
- Одно главное действие на экран. Оно получает акцент; всё остальное нейтральное.
- Состояния загрузки, пустоты, ошибки и отсутствия сети — у каждого экрана, где есть данные извне.
- Тексты: короткие, по-русски, глагол в кнопке совпадает с результатом («Добавить в обед» → тост «Добавлено в обед»).

## ★1. Сегодня (главная)

**Задача:** открыл — увидел тренировку на сегодня — начал. Ниже — коротко питание, шаги, восстановление и один совет.

```
┌ Сегодня                     🔔 ┐  AppHeader: «Сегодня», дата под заголовком
│ Понедельник, 2 ноября           │
│                                  │
│ ┌ Тренировка ─────────────────┐ │  главная карточка (surface1, radius.lg)
│ │ Низ Б                        │ │  title2
│ │ 7 упражнений  ~50 мин        │ │  callout, колонки, без «·»
│ │ Ягодицы, бицепс бедра, икры  │ │
│ │ [ ▶ Начать тренировку      ] │ │  PrimaryAction
│ └──────────────────────────────┘ │
│                                  │
│ Питание                   Дневник│  SectionHeader + действие
│ 1 240 из 2 890 ккал              │  StatRow: число крупно
│ ├──┼──┼──┤  Белки 62/145 г       │  MacroSummary: 3 шкалы с делениями
│ ├──┼──┼──┤  Жиры 40/70 г         │
│ ├──┼──┼──┤  Углеводы 130/420 г   │
│                                  │
│ ┌ Шаги       6 840 / 7 000     ┐ │  сгруппированный список StatRow
│ │ Сон        7 ч 20 мин        │ │
│ │ Восстановление  Хорошее      │ │  без чек-ина: «Пройти чек-ин ›»
│ └──────────────────────────────┘ │
│                                  │
│ ┌ RYNJI ────────────────────────┐│  CoachInsight: один совет
│ │ Белка не хватает 83 г. Ужин   ││
│ │ с творогом закроет половину.  ││
│ │ Почему?          Добавить ›   ││
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

Состояния:
- **Отдых:** вместо карточки тренировки — «Сегодня отдых», восстановление крупно и «Ближайшая: Верх А, завтра ›».
- **Тренировка выполнена:** карточка «Низ Б выполнена — 52 мин, 18 подходов», действие «Итоги».
- **Идёт тренировка:** карточка «Продолжить: 3 из 7 упражнений».
- **Нет Health:** строка «Шаги — подключить Apple Health ›», только в одном месте.
- **Нет плана:** «Заполни анкету — RYNJI составит план».

Убираем: плитки «Калории» и «Белки» (дубль), карточку «Активность за 7 дней» (дубль пустого состояния), картинку штанги в совете, фоновое свечение, манекен в карточке тренировки, воду с главной (остаётся в «Питании»).

## ★3. Активная тренировка — одно упражнение = один экран

**Задача:** увидел упражнение, предыдущий результат и предложение RYNJI → подтвердил или исправил вес и повторы → отметил подход. Таймера отдыха нет.

```
┌ ✕   Упражнение 3 из 7    12:40 ⋯┐  компактная шапка: позиция и время мелко
│ ━━━━━━━━━━━━━━━━━━━━──────────── │  прогресс тренировки 2 pt
│                                  │
│ Жим гантелей на наклонной        │  title1, слева
│ Грудь, передние дельты           │  callout, без капса
│                                  │
│ Прошлый раз   24 кг × 10, 10, 9  │  StatRow
│ RYNJI         26 кг × 8–10       │  StatRow с дельтой «+2 кг» (positive)
│                                  │
│  №   Вес, кг   Повторы  RIR      │  подписи колонок caption
│ ✓1    26        10       2       │  выполненный — textSecondary + метка
│ ▸2   [26]      [ 9 ]    [—]      │  текущий: поля ввода, display-цифры
│  3    26        8–10             │  будущий: textTertiary
│ + Подход                         │
│                                  │
│ ▾ Техника                        │  свёрнутый блок внизу, одна строка
├──────────────────────────────────┤
│ ‹      [ ✓ Записать подход 2 ]  › │  одна панель: PrimaryAction по центру
└──────────────────────────────────┘
```

- Подход заполнен предложением RYNJI. «Записать подход» — подтверждение, правка поля — исправление.
- Суперсет: метка «Суперсет A1 → A2» под названием; «›» ведёт к следующему участнику.
- Упражнение на время: колонки «Время» вместо «Вес / Повторы», кнопка «Старт».
- Кардио (этап 4): колонки «Время, Дистанция, Темп» — без «кг».
- «Техника» раскрывается вверх до 45% высоты. Подходы над ней остаются видны.
- Список упражнений, замена и заметка — в меню «⋯» и в листе списка.

Убираем: таймер 34 pt как главный элемент, вторую нижнюю панель, свечение кнопки, капс в названии мышц.

## 4. Упражнение (карточка из библиотеки)

## ★5. Питание (дневник)

**Задача:** выбрал день → увидел, сколько съедено, сколько осталось, Б/Ж/У → «+» у приёма пищи → добавил.

```
┌ Питание                      ⋯ ┐  AppHeader; ⋯ — копировать день, цели
│ Пн  Вт  Ср  Чт  Пт  Сб  Вс      │  WeeklyDateStrip, сегодня в рамке,
│  2   3   4   5   6   7   8      │  точка под днём — есть записи
│  •   •                          │
│                                  │
│ Осталось                         │
│ 1 650 ккал                       │  display
│ Съедено 1 240 из 2 890           │  callout
│ ├──┼──┼──┼──┼────┤ Белки 62/145 │  MacroSummary: шкалы с делениями
│ ├──┼──┼──┼──┼────┤ Жиры 40/70   │
│ ├──┼──┼──┼──┼────┤ Углев. → полностью «Углеводы»
│                                  │
│ ┌ Завтрак            520 ккал + ┐│  MealSection
│ │ Овсяные хлопья  60 г     220  ││  FoodRow
│ │ Творог 5%  · Простоквашино    ││  бренд вторым рядом
│ │ 180 г                    218  ││
│ ├ Обед               720 ккал + ┤│
│ │ …                              ││
│ ├ Ужин                        + ┤│  пусто: «Повторить вчерашний ужин»
│ ├ Перекус                     + ┤│
│ └──────────────────────────────┘│
│ Вода 1,25 из 2,75 л   [−] [+250] │
└──────────────────────────────────┘
```

- Свайп по продукту — «Удалить», затем тост «Удалено · Отменить».
- Тап по продукту — порция. Долгое нажатие — «Копировать в…», «Сохранить как блюдо».
- Прошлый день: те же действия, запись задним числом.
- Нет плана питания: «Заполни профиль — RYNJI рассчитает КБЖУ».

Убираем: кольцо 212 pt, крупную кнопку «Добавить еду» со свечением (её роль — у «+»), обрезанные подсказки «+ Обычный…».

## ★6. Поиск и добавление продукта

**Задача:** найти продукт за 1–2 действия, выбрать порцию, добавить в выбранный приём. Повторный продукт — не больше 3 ключевых действий.

```
┌ ‹  Добавить в обед         Готово┐  title2; «Готово» при корзине > 0
│ [🔍 Продукт, бренд или штрихкод ]│  поле поиска, автофокус
│ [ Сканировать ]  [ Свой продукт ]│  SecondaryAction × 2
│ ( Недавние | Избранное | Мои )   │  SegmentedControl, подписи целиком
│                                  │
│ Творог 5%                  121 ⊕ │  FoodRow: ккал на 100 г
│ Простоквашино · на 100 г         │  бренд и база
│ Творог 5%                  121 ⊕ │
│ Базовый продукт                  │
│ Куриная грудка отварная    137 ⊕ │
│ …                                │
│ ── Open Food Facts ──────────────│  группа результатов из сети
│ Творог 5% Домик в деревне  … ⊕   │  метка «не проверено»
│                                  │
├──────────────────────────────────┤
│ В обеде: 2 продукта · 420 ккал   │  панель корзины (видна, если > 0)
│ [ Добавить в обед ]              │  PrimaryAction
└──────────────────────────────────┘
```

Тап по строке открывает лист порции: количество, единица («г / мл / шт / порция»), быстрые варианты «как в прошлый раз», «100 г», «упаковка», мгновенный пересчёт КБЖУ, источник и статус. Действия: «Добавить в обед» или «В корзину».

Состояния: идёт поиск (скелетоны под локальными результатами — ввод не блокируется); ничего не найдено («Ничего не нашлось. Проверь написание или добавь продукт с этикетки»); нет сети («Нет сети — ищу в сохранённых и базовых продуктах»); ошибка сервиса («База продуктов не отвечает. Повторить»).

## ★7. Прогресс и аналитика

**Задача:** за 7 / 30 / 90 дней понять тренд веса, силы и питания. Где данных мало — так и сказать.

```
┌ Прогресс                      + ┐
│ ( 7 дней | 30 дней | 90 дней )   │  SegmentedControl
│                                  │
│ Вес                              │
│ 79,6 кг     +0,5 кг за 30 дней   │  display + дельта
│ ╭───────────────────────────╮    │  линия тренда, точки взвешиваний тише
│ │      ___/‾‾\__/‾‾‾        │    │  ось с 3 подписями
│ ╰───────────────────────────╯    │
│                                  │
│ Питание за 30 дней   Дней с записями 22 из 30
│ ┌ Среднее        2 610 ккал    ┐ │  StatRow
│ │ Цель           2 890 ккал    │ │
│ │ Белки          131 г   90%   │ │  с цветом данных
│ │ Жиры           72 г    103%  │ │
│ │ Углеводы       318 г   76%   │ │
│ └──────────────────────────────┘ │
│ ▁▃▅▂▆▇▃▅  ккал по дням           │  столбики, цель — линия
│                                  │
│ Тренировки                       │
│ ┌ Тренировок     12            ┐ │
│ │ Объём          56 680 кг +12%│ │
│ │ Рекорды        8         ›   │ │
│ └──────────────────────────────┘ │
│ Связь веса и питания: средний    │  только при ≥ 14 днях с записями
│ профицит ~280 ккал — темп +0,3   │  и ≥ 4 взвешиваниях; иначе
│ кг/нед совпадает с целью.        │  «Недостаточно данных: нужно ещё 6 дней»
└──────────────────────────────────┘
```

Детали — по тапу: тело, статистика упражнений, отчёт недели, анализы.

## 8. Профиль

`AppHeader` с аватаром и целью; сгруппированные списки: личные данные; цели и тренировки; питание; здоровье (сон, активность, восстановление, ограничения, анализы, мониторинг); RYNJI Coach (память и факты); оформление; уведомления; Apple ID, данные и резервные копии. Демо-функции — только в сборке разработки.

## 9. Coach

Чат с контекстом. На главной — один `CoachInsight`; в дневнике — подсказка по остатку КБЖУ; в тренировке — строка предложения. Каждое предложение изменить план — карточка «Применить / Не менять». Без подтверждения ничего не применяется.

## 10. Онбординг

5 этапов по эталону этапа 2 без изменения сценария. Перевод на новые токены и типографику; заголовки этапов — `title1`; кнопка «Продолжить» — `PrimaryAction`.
