# RYNJI 2.0 — UX-аудит (фаза A)

Дата: 2 ноября 2026. Ветка `claude/exciting-brown-szjuk7` поверх `main` (PR #26 влит).

**Как проверялось**
- Прочитан код: `src/theme/index.ts`, `src/components/*`, `src/app/(tabs)/*`, `src/app/food/*`, `src/features/nutrition/*`, `src/stores/nutrition.ts`, `src/services/foodApi.ts`, `src/app/workout/*`, `server/index.mjs`.
- Сняты экраны текущей версии. Это **web-рендер 393×852 pt, а не iPhone**: тёмная и светлая темы, демо-история за 4 недели. Скриншоты лежат в `docs/design/before/`.
- Базовые проверки до любых изменений: `tsc` — без ошибок, `expo lint` — без ошибок, юнит-тесты — 183 из 183. `expo-doctor` — 1 проверка не пройдена: 18 пакетов SDK 58 отстают по патч-версиям.
- На реальном iPhone ничего не проверялось. Dynamic Island, нативные модальные окна, VoiceOver и Dynamic Type на устройстве — **не проверено**.

## 1. Почему интерфейс читается как «шаблонный»

Цифры получены grep-ом по `src/`.

| # | Наблюдение | Цифры | Почему мешает |
|---|---|---|---|
| G1 | Нет шкалы типографики: размер шрифта переопределяется прямо в разметке | 311 переопределений `fontSize`, 24 разных размера. 10 pt — 13 раз, 11 pt — 46, 12 pt — 109 | Мелкий серый текст повсюду. Иерархия держится на жирности, а не на структуре. Крупный шрифт iOS (Dynamic Type) ломает вёрстку. |
| G2 | Почти всё набрано сверхжирным | `fontWeight: '800'` — 72 раза | Всё «кричит», ничего не главное. |
| G3 | 33 разных радиуса скругления | 33 значения `borderRadius` | Карточки, кнопки и чипы «почти одинаковые» — признак набора по месту. |
| G4 | Одинаковые карточки на каждом экране | `<Card>` — 60 использований | Главная — колонка из 9 похожих карточек. Нет различия между главным и второстепенным. |
| G5 | Декоративные эффекты | фоновое свечение `Ambient` на 12 экранах, `CtaGlow`, `Sheen`, счётчики `useCountUp` при каждом открытии | Неоновый «игровой» эффект. Анимация без действия пользователя. |
| G6 | Лайм занят под всё сразу | В тёмной теме `carbs` = `accent` = `#C8F53C` | Углеводы, кнопка «Начать», «выполнено», «RYNJI» и активная вкладка — один цвет. Цвет перестаёт что-либо значить. |
| G7 | Фон — чистый `#000000` | `DARK_BASE.bg` | Холодный OLED-чёрный плюс кислотный лайм — самое типовое сочетание «AI-фитнеса». Бриф задаёт `#0D1118`. |
| G8 | Процедурный серый манекен как главная иллюстрация | карточка «Сегодня», 3D-петли | Безликая фигура без лица — самый «сгенерированный» элемент интерфейса. Бриф: не считать финальной базой. |
| G9 | Метаданные склеены точками | «~50 мин · 18 подходов», «Б 17.2 · Ж 5 · У 1.8» десятки раз | Шаблонная подача. Плюс десятичная точка вместо запятой: `17.2` вместо `17,2`. |
| G10 | ВСЕ ЗАГЛАВНЫЕ для подписей | «СПИНА» в активной тренировке | Типовой «технологичный» приём, хуже читается. |
| G11 | Эмодзи в данных интерфейса | 23 эмодзи в `src` (🙂 🔥 🏆 в истории и итогах) | Бриф: «без случайных emojis». |
| G12 | Подписи сегментов обрезаются | «★ / Час… / Нед… / Мои / Базо…» в «Добавить еду» | Пользователь не видит, что за вкладка. |

## 3. Технические риски

| Риск | Где | Что делать |
|---|---|---|
| «Общий секрет» `EXPO_PUBLIC_COACH_KEY` попадает в сборку приложения, его можно извлечь | `src/services/coachApi.ts`, `labExtract.ts`, `bodyPhoto.ts` | Это не секрет. Нужна авторизация устройства на сервере (фаза C/F). Ключ FatSecret в приложение не класть. |
| `EXPO_PUBLIC_FDC_KEY` (USDA) в сборке | `src/services/foodApi.ts` | Ключ USDA публичного уровня — допустимо, но лучше через тот же прокси |
| 18 пакетов SDK 58 отстают | `expo-doctor` | `npx expo install --check` отдельным коммитом с полным прогоном тестов (фаза B) |
| Тема сделана через подмену цветов по совпадению значения (`themed()` → `recolor`) | `src/theme/index.ts` | Новая палитра должна сохранить уникальность значений токенов: два токена с одним цветом ломают перекраску. Сейчас `carbs` = `accent` |
| e2e завязаны на тексты и `testID` экранов | `scripts/e2e-web.cjs` (50 сценариев) | Менять `testID` только вместе со сценарием; тексты — через константы |

## 4. Что сохраняем без изменений

Логика планов и прогрессии; хранилища Zustand и ключи `form.*`; история тренировок; снимок КБЖУ в записи дневника (`FoodEntry.macros`); офлайн-продукты; подтверждение рекомендаций (ничего не применяется без «Применить»); Apple Health; Live Activities; «одно упражнение — один экран»; отсутствие таймера отдыха.
