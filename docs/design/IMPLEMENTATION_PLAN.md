# RYNJI 2.0 — план внедрения

Работа идёт в ветке `claude/exciting-brown-szjuk7` (решение владельца от 2 ноября 2026; бриф предлагал `design/rynji-2`). Коммиты небольшие и логические. PR по фазе — по запросу владельца.

## Общий порог для каждой фазы

Фаза не считается готовой, пока не выполнены все пункты:
1. `npm run typecheck`, `npm run lint`, `npm test`, `npm run doctor` (известное отставание 18 пакетов закрывается в фазе B).
2. Web e2e (`scripts/e2e-web.cjs`, сейчас 50 сценариев), доступность при шрифте ×1,5 (`scripts/a11y-web.cjs`), обход экранов (`scripts/crawl-web.cjs`), iOS-экспорт (`npx expo export --platform ios`).
3. Снимки «до / после» затронутых экранов в `docs/screens/<фаза>/` с пометкой «web-рендер».
4. Перечень изменённых файлов и известных ограничений в отчёте фазы.
5. Всё, что нельзя проверить без iPhone (Dynamic Island, Live Activity, VoiceOver, нативные листы, Health, сканер), помечается **«не проверено на устройстве»**.

Данные: перед изменением схемы хранилища — миграция с версией persist и unit-тестом на фикстуре прошлой версии. Ключи `form.*` не меняются. Старые резервные копии продолжают импортироваться (тест).

## Фаза E — Прогресс, профиль, Coach, восстановление, онбординг, иллюстрации

- Прогресс и аналитика по ★7; профиль на сгруппированных списках; Coach в контексте; онбординг на токенах.
- Анатомия: единый арт-пайплайн только после лицензированной rigged-модели (решение владельца: бюджет и лицензия). До этого — нейтральная схема мышц. 6 текущих петель не выдаются за 114 упражнений.

**Статус:** E1–E4 выполнены, ждут ревью владельца. Итог, проверки, снимки и решения, которые нужны от владельца (приветствие со свечением, карточки целей с 3D-торсами), — `docs/screens/phaseE/README.md`.

## Фаза F — доступность, производительность, полировка, App Store

- VoiceOver-проход по всем экранам; Dynamic Type до AX5 на ключевых экранах; Reduce Motion; контраст обеих тем.
- Профилирование длинных списков (история, дневник за год) на устройстве; оптимизация только по замерам.
- Снимки регрессии дневника и активной тренировки (web) в CI.
- Проверка на реальных iPhone: маленький (SE/mini), с Dynamic Island, светлая и тёмная тема.
- Подготовка к App Store: иконки, скриншоты, тексты, политика конфиденциальности.

## Зависимости

Новые библиотеки в фазах B–D **не нужны**: Reanimated, Gesture Handler, Expo Haptics, Expo Router, react-native-svg и expo-image уже в проекте. Возможные кандидаты, каждый — отдельным решением после проверки совместимости с SDK 58 через `npx expo install`:

| Кандидат | Зачем | Когда |
|---|---|---|
| `expo-symbols` | SF Symbols вместо Ionicons | после проверки на устройстве (фаза F) |
| `@shopify/flash-list` | дневник и история > 1000 строк | только если профилирование покажет проблему FlatList |
