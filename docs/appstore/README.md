# RYNJI — подготовка к App Store (фаза F)

Черновики для владельца. Ничего не отправлено в App Store Connect: это делает владелец со своей учётной записью Apple Developer.

## Что готово в проекте

| Пункт | Состояние |
|---|---|
| Иконка | `assets/icon.png` 1024×1024, RGB без прозрачности — подходит для App Store |
| Bundle ID | `net.fontvielle.form` (`app.json`), версия `1.0.0`, номер сборки — удалённый автоинкремент EAS (`eas.json`, `production.autoIncrement`) |
| Описания разрешений | камера (штрихкоды, фото бланков), фото (фото прогресса и бланков), чтение Apple Health. Запись в Health не запрашивается, микрофон не запрашивается |
| Манифест приватности | `ios.privacyManifests` в `app.json`: без слежения, собираемых данных нет, причины API — объединение манифестов зависимостей (UserDefaults CA92.1; FileTimestamp C617.1, 0A2A.1, 3B52.1; DiskSpace E174.1, 85F4.1; SystemBootTime 35F9.1) |
| Шифрование | `ITSAppUsesNonExemptEncryption: false` — только HTTPS системными средствами |
| Пакеты SDK 58 | обновлены до ожидаемых версий, `expo-doctor` — 20 из 20 |
| Вход | только Apple ID (или без входа в сборке разработки). Аккаунт хранится на устройстве: «Профиль → Аккаунт → Отвязать Apple ID»; «Удалить все данные» стирает всё |
| Экспорт данных | «Профиль → Данные и резервные копии»: файл со всеми данными и CSV тренировок |

## Тексты

- `metadata-ru.md` — название, подзаголовок, ключевые слова, описание, «Что нового».
- `privacy-policy-ru.md` — политика конфиденциальности (нужна ссылка в App Store Connect и в приложении: Apple требует её для приложений с HealthKit).
- `app-privacy.md` — ответы на раздел «Конфиденциальность приложения» в App Store Connect.

## Снимки для витрины

`screenshots-draft/` — **черновики, web-рендер** 1320×2868 (размер iPhone 6,9″, который принимает App Store), шрифт Inter вместо SF Pro, без строки состояния, данные — демо-история. Для публикации снять заново на iPhone или в симуляторе (на устройстве не проверено).

## Что нужно от владельца

1. **Учётная запись Apple Developer** и запись приложения в App Store Connect с этим Bundle ID; включить HealthKit и Sign in with Apple для идентификатора.
2. **Адрес политики конфиденциальности и поддержки**: опубликовать `privacy-policy-ru.md` (например, на своём сайте) и указать URL.
3. **Режим Enhanced** (мониторинг для тех, кто сообщает о приёме AAS): хранит записанные пользователем вещества и дозы и показывает предупреждения и анализы, без схем и дозировок. Правило App Review 1.4.3 запрещает поощрять употребление препаратов; формулировки — снижение вреда, но решение, оставлять ли режим в первой версии, — за владельцем.
4. **AI-сервер тренера**: сейчас во всех профилях сборки `EXPO_PUBLIC_COACH_API_URL` пуст — тренер отвечает на устройстве, распознавание анализов и фото недоступно, и приложение так и пишет. Если сервер включить, контекст (профиль, питание, тренировки, сон, данные Health) уходит на сервер владельца и в Anthropic — тогда нужно обновить политику, ответы `app-privacy.md` и манифест, а общий ключ `EXPO_PUBLIC_COACH_KEY` заменить авторизацией устройства (секрет в сборке извлекается).
5. **Возрастной рейтинг**: медицинская и оздоровительная информация — «нечасто/умеренно»; без насилия и пользовательского контента. Предлагаемая категория — «Здоровье и фитнес», дополнительная — «Спорт».
6. **Проверка на iPhone** — см. список в `docs/screens/phaseF/README.md`.
