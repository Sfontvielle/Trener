# Live Activities и Dynamic Island — активная тренировка

## Как устроено

| Часть | Файл | Что делает |
|---|---|---|
| Данные активности | `src/features/training/liveActivity.ts` | Чистое отображение `useWorkouts.active` + `rest` → `WorkoutActivityProps`: тренировка, текущее упражнение (в суперсете — выбранное сейчас, метка A1/A2), «Подход N из M», запланированные вес × повторы, для упражнений на время — секунды, «Далее: …», прогресс, начало тренировки, отдых (только если запущен вручную) |
| Согласование | `src/features/training/liveActivitySync.ts` | Ровно одна активность на тренировку: старт, обновление только при изменении данных, закрытие лишних и активностей прошлых тренировок; завершение — итог 2 минуты, отмена — сразу; после перезапуска приложения существующая активность принимается, «висящая» без тренировки закрывается; смахнутую пользователем не навязываем снова до перезапуска; запрещены или не поддерживаются — без повторов, тренировка работает как обычно |
| Нативная связка | `src/services/liveActivity.ts` | Ленивая загрузка `expo-widgets` (в Expo Go и web — выключено), подписка на `useWorkouts` и единицы веса, повторное согласование при возвращении в приложение |
| Вёрстка | `src/widgets/WorkoutActivity.tsx` | `createLiveActivity` с директивой `'widget'` на `@expo/ui/swift-ui`: экран блокировки (подробно), компактный Dynamic Island (значок + «2/4» или отсчёт отдыха), минимальный (значок), расширенный (подход, секундомер или отдых, упражнение, вес × повторы, прогресс, «далее») |
| Запуск | `src/app/_layout.tsx` | `startWorkoutActivitySync()` после загрузки данных |
| Конфигурация | `app.json` | плагин `expo-widgets` (`enablePushNotifications: false`, `frequentUpdates: false`) — добавляет расширение `ExpoWidgetsTarget`, `NSSupportsLiveActivities`, App Group `group.net.fontvielle.form` |

Состояние — только из существующего хранилища тренировок: второй истории подходов нет. Сервер и push не используются:
активность обновляет само приложение. Секундомер тренировки и обратный отсчёт отдыха тикают в самой
активности (`Text date` / `timerInterval`), без обновлений раз в секунду. Тап открывает `form://workout/active`.

Автоматического таймера отдыха нет: отдых в активности появляется, только если его запустили кнопкой ⏱.

## Сборка для проверки

Live Activities не работают в Expo Go — нужна development build:

```bash
npx eas-cli@latest build --profile development --platform ios
```

При первой сборке EAS предложит зарегистрировать App Group `group.net.fontvielle.form` и права (Sign in with Apple,
App Groups) для основного приложения и расширения `ExpoWidgetsTarget` — согласиться. Минимальная iOS — 16.4.

## Чек-лист на iPhone

Проверить на iPhone с Dynamic Island (14 Pro и новее) и на iPhone без него (например, SE / 13) — там активность
видна только на экране блокировки и в баннере.

1. Начать тренировку → на экране блокировки появилась одна активность: название тренировки, упражнение, «Подход 1 из N», вес × повторы, секундомер идёт.
2. Dynamic Island (компактный): значок и «1/N»; долгое нажатие — расширенный вид с подходом, секундомером, упражнением и «далее».
3. Завершить подход → «Подход 2 из N», полоса прогресса выросла. Последний подход упражнения → «Готово · N из N» и «Далее: …».
4. Перейти к другому упражнению (стрелки или список) → название и подходы сменились.
5. Суперсет: после подхода A1 активность показывает A2 (фактически выбранное упражнение).
6. Упражнение на время (планка) → показывается время подхода «0:45», без кг и повторов.
7. Нажать ⏱ → в активности обратный отсчёт отдыха; остановить → отсчёт пропал. Без нажатия отдых не появляется.
8. Тап по активности → открывается экран текущей тренировки.
9. Завершить тренировку → активность показывает итог и исчезает через ~2 минуты. Отменить («Удалить») → исчезает сразу.
10. Закрыть приложение смахиванием во время тренировки, открыть снова → та же одна активность обновилась, вторая не появилась.
11. Настройки → RYNJI → выключить Live Activities → начать тренировку: всё работает, активности нет, ошибок нет. Включить и вернуться в приложение → активность появилась.
12. Смахнуть активность с экрана блокировки → во время этой тренировки она не возвращается.
13. Режим полёта на всё время проверки → всё работает (сеть не нужна).
